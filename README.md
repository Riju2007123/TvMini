# TVMini

A small animation studio: draw, tween, and export `.clip` files that open in
Clip Studio Paint. Imports Flash 8 (`.fla`/`.xfl`) with vectors, layers and
tweens intact.

- **Download the desktop app (free, no install):**
  https://github.com/Riju2007123/TvMini/releases/latest —
  unzip anywhere, double-click `TVMini.exe` (Windows 10/11, 64-bit).
  Unsigned, so SmartScreen may ask for *More info → Run anyway* on first launch.
- **Use it in the browser, nothing to download:**
  https://riju2007123.github.io/TvMini/

This repository carries the finished app — the download, the browser version
and the licence. It holds no sources.
