About TVMini

TVMini is a clean-room implementation of a Clip Studio Paint-like paint application.

Built for experimentation with brush formats, timeline models, and paint semantics.

This is a shareable static build — no backend required.

Feedback

No data is saved or sent. This is a local-only demo.

Keyboard Shortcuts

Press ? to toggle this panel, Esc to close overlays, S to play/pause timeline.

  • C: Camera tool
  • S: Timeline playback
  • F1: Help
  • Esc: Close dialogs/overlays
