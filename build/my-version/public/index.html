    Drawing

    Draw with Brush (B). Eraser (E) removes paint and reveals lower layers or the canvas. Pick (I) samples a colour from the canvas. [ and ] change the brush size.

    Pen pressure follows the stylus. The pressure gain slider makes strokes respond harder or softer. Draw with touch decides whether a finger draws; a stylus always draws.

    Line (L), Rect (R) and Oval (V) are drag tools: press, drag to the size you want, release. Fill (F) is a paint bucket: click a region and the colour floods it, stopping at the stroke edges. The stabiliser slider calms shaky lines, stroke opacity makes a stroke see-through, and blend mixes it with the paint underneath (normal, multiply or screen).

    Undo / redo is Ctrl+Z, Ctrl+Y (or Ctrl+Shift+Z), and covers strokes, layers, timeline edits and pixels cleared with Backspace.

    Timeline

    Each layer row shows one column per frame. A filled dot is a drawing's first frame; lighter dots are held frames. 6 inserts a blank drawing, 5 lengthens the current exposure, Shift+5 shortens it, Delete removes the drawing, Ctrl+D duplicates it. Space plays, ←/→ step frames, ↑/↓ change layer.

    Layers

    Layers composite top to bottom in the list. Move them with the ↑/↓ buttons, rename with a double-click on the timeline name, and lock or hide with the eye and lock icons.

    Saving and files

    With the Node server (node server.js) files are saved on disk as .tvmini and the app remembers real paths. On a static host (such as GitHub Pages) saving uses the browser's own download or File System Access API, and recent projects are kept in this browser.

    Importing a .clip reads the saved canvas preview of a Clip Studio file — the original is never changed. Exporting a .clip writes the current frame as separate raster layers inside a fresh Clip Studio document.
